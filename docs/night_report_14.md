## 2. 退行の決着（`docs/regression_check.md` §8〜§10）

### 2.1 監査（学習なし）

| 項目 | 結果 |
|---|---|
| `set_seed` が触るもの | python `random`、numpy、torch CPU、torch CUDA（全デバイス）。deterministic 系のフラグ、TF32、dtype はどこでも設定していない（パラメータはすべて float32） |
| モデル生成時に乱数で決まるパラメータ | **`scorer.weight` の 1 つだけ**（157 個のうち） |
