## 4. 検定と判定（`scripts/seed8_stats.py`、`tests/test_seed8_stats.py`）

**主検定（優越）**: M2 について、統計量 = mean(long12) − mean(base12)。**片側の正確置換検定**で、C(16, 8) = 12,870 通りを
すべて列挙します。p = （統計量が観測値以上になる分け方の数）/ 12,870（観測値そのものを含むので、最小は 1/12,870）。
**α = 0.05**。検定はこの 1 本だけで、多重性の補正はしません。

**非劣化検定**（すべて通ることを要求する intersection-union 型。α の補正はしない）: long12 の各値にマージンを
有利な方向に足し（RPS は引き）、base12 に対して同じ片側の正確置換検定を行って、p < 0.05 で通過とします。

| 指標 | マージン | long12 に加える量 |
|---|---|---|
| M1 | −0.005 | +0.005 |
| M5 | −0.01 | +0.01 |
| choice acc | −0.005 | +0.005 |
| score acc | −0.01 | +0.01 |
| bool acc | −0.005 | +0.005 |
| score RPS | +0.005 | −0.005（base12 − long12' を統計量にする） |

**記述統計**（判定には使わない）:

- 各指標の平均差（long12 − base12）について、条件内でシードを復元抽出するブートストラップの 95% 区間を出します
  （10,000 回、パーセンタイル法、numpy の乱数シード 20260925）。
- base12 と参照（v0.1、batch 24）の seed 0〜2 どうしを並べます（バッチの組み方の効果の記述）。
- long12 の 8 本平均と参照の 3 本平均の差を出します（出荷中の v0.1 との実質的な差）。

**判定**:

- **採用候補**: 主検定 p < 0.05、かつ非劣化検定がすべて通る。long12 を新しい候補とします。bench は実行しません。
- **トレードオフ**: 主検定は通るが、非劣化で落ちるものがある。どの指標で、どれだけ落ちたかを記録します。
- **長さの効果は未検出**: 主検定 p ≥ 0.05。question_first での長文追加というレバーを閉じます。
- 前回の型 B の判定は書き換えません。`docs/length_2x2.md` には「追補」として参照を足すだけにします。

**破損停止**: 各条件の最初の新規シード（base12 seed 0、long12 seed 3）の M1 が **0.854142**
（参照 3 本の最小 0.881718 − 2 × 参照の幅 0.013788）を下回ったら、その条件を止めて記録します。

**打ち切り**: 終了処理の開始までに 8 対 8 がそろわなければ検定はしません。そろった分の記述統計だけを出し、判定は TBD とします。
