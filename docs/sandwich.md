## 1. 実装（`--input-order sandwich`）

- **系列**: `<s>` 指示 `</s><s>` 選択肢+`<mask>` `</s><s>` **state** `</s><s>` 指示 `</s><s>` 選択肢+`<mask>` `</s>`
  （`prefix + Q + separator + state + separator + Q + suffix`）。
  - 区切りは既存の `SpecialTokenLayout` のものです。
  - 前後 2 つの質問ブロック Q は、同じトークン列です。
- **mask の扱い**: 各 mask スロットについて、前後の位置のペアを記録します（`EncodedJoint.marker_positions` と `marker_positions_back`、
  前の i 番目と後ろの i 番目が対）。
  - モデルは 2 つの hidden state を平均してから、既存のスコアラ・ordinal ヘッドに渡します。ヘッドは変更していません。
  - 平均化は `sokudan/model/joint.py` の `gather_marker_states` 1 か所だけです。choice / score / bool の分岐より前にあるので、3 種で共有されます。
  - モデルは、`sandwich` 以外で後ろの位置を受け取るとエラーにします。`sandwich` で後ろの位置が無い場合もエラーにします。
- **経路**: 学習・評価（`JointCollator`、`run_model`）と `predict.py` は、同じ `encode_joint` を通ります。
  入力順はチェックポイントに保存され、読み込み時に復元されます。
- **切り詰め**: 上限 1,024 は変えていません。質問ブロック 2 つ分を除いた残りを state に使います。

## 3. 条件と判定規則

- **条件**: sandwich を seed 0〜7 で 8 本学習します（`scripts/sw_train.py`）。
  - 設定: batch 24、累積 1、`--local-attention` なし、`data/train_v2b.jsonl`。
  - それ以外は v0.1 と同じで、VRAM 上限も同じです。
- **比較相手**: v0.1 の 8 本（`runs/v01_seed0〜7`）と io_sf の 8 本（`runs/io_sf_seed0〜7`）。どちらも既存で、再学習はしません。
- **H1**: M2 で sandwich > v0.1（片側の正確置換検定、8 対 8、12,870 通り）。
- **H2**: M5 で sandwich > sf（同上）。
- **H1 と H2 に Holm 補正**をかけ、α = 0.05 で判定します（`scripts/sw_test.py`）。
- **解釈**:
  - 両方とも棄却 → 「両取りの兆候」。採用に向けた評価は、別の実験として設計します。
  - H1 だけ棄却 → 長文の効果は保てたが、断りは戻らなかった。
  - H2 だけ棄却 → 断りは戻ったが、長文の効果は消えた。
  - どちらも棄却できない → サンドイッチは閉じる。
- **参考**（判定には使わない。M5 の SD に対して検出力が足りないため）:
  - M5 の sandwich と v0.1 の差について、マージン −0.01 での非劣化検定（sandwich + 0.01 > v0.1、片側の正確置換）の p 値と、
    ブートストラップ 95% 区間（numpy の乱数シード 20260926、10,000 回）。
  - M1m、M1、ガードレールの差と区間（対 v0.1、対 sf）。
- 比較のための既存値（8 本平均）: M2 は v0.1 0.8372、sf 0.8821。M5 は v0.1 0.7818、sf 0.7378。

## 8. チャット側の判断（2026-09-26 に記録。上の事前登録と判定は変更していない）

1. サンドイッチは閉じる。入力形式のレバー（qf / sf / sandwich / 窓 1024）は一巡したので、ここで閉じる。
2. 遮蔽分析で「断りの手がかりは冒頭」は外れた。サンドイッチの結果で「mask が近い端が有利」という説明も支持を失った。
   暫定の読みは次のとおり。
   - sf は末尾の文に頼るように偏る（Q3 の後 1/3: 0.71 対 0.58）。
   - 末尾に意図がある長文では得をし、中盤に手がかりがある断りでは損をする（Q2 の中 1/3: 0.435 対 Q1 の 0.316、n = 46）。
3. v0.1 自身のシード間の揺れ（M2 の SD 0.036、M5 の SD 0.037）が、どの介入の効果よりも大きい。次は分散を削るレバーを試す
   （`docs/ensemble.md`）。
