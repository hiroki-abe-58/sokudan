## 2. Phase 1 で分かったこと

- **「1024 で全層が実質 global」は 513 トークン以下の系列でだけ成り立ちます。**
  transformers 5.17.0 では `local_attention` は窓の全幅で、`sliding_window = local_attention // 2`、
  マスクは `|q − kv| ≤ sliding_window`。1024 は ±512 です。
- sliding 層は RoPE base 10,000 のまま（global 層は 160,000）。窓を広げても位置の扱いは変わりません。
- 上書きはモデル構築前に config に入れる必要があります（sliding 層が構築時に
  `sliding_window + 1` を保持するため）。`Backbone.load(local_attention=...)` の 1 箇所で実施。
  チェックポイントには実際の値を保存し、`load_checkpoint` / `predict.py` が復元します。
- テスト: 60 トークンで 128 と 1024 の出力差は **0**（基準 ≤ 1e-4）、320 トークンで max **26.1**
  （基準 > 5e-2）、保存→再読込で 1024 が保たれ、キーの無い v0.1 は 128 で読まれる。
- **系列長**: どのセットにも 1024 超はありません。**学習データは最長 443 トークン**（joint）で、
  513 を超えるのは評価側 `docs_long_val` の 72 行だけ。frozen yardstick の 400–799 帯は
  6 行しかないため、M2 は `docs_long_val` の held-out 行（204）と合わせて n=210 で定義しました。

## 4. 意外だったこと

1. **位置依存属性は窓を広げると悪化しました。** `ends_with_question` acc 0.634 → 0.535、
   AUROC 0.708 → 0.582（ほぼ偶然水準）。構造依存の `uses_bullet_points`（参考）も 0.727 → 0.651。
   「窓 128 が位置依存属性を弱くしている」という仮説は、この測定では支持されません。
2. **held-out が全般に下がる一方、学習分布側の val は少し良くなりました**（score RPS 0.1664、
   score acc 0.5392、bool acc 0.9335 は v0.1 の 3 シードのどれより良い）。1 シードなので
   これを改善とは言えませんが、「窓を広げると学習分布へのあてはまりが上がり、未知属性への
   転移が落ちる」形になっています。
3. **長さ帯の低下は消えず、急になりました**（帯別 AUROC、v0.1 s0 → 1024: 0–199 0.886 → 0.865、
   200–399 0.862 → 0.824、400–599 0.866 → 0.784、600–799（n=33、参考）0.730 → 0.476）。
   600 超は joint で 513 を超え、1024 でも sliding 層が局所的になる領域で、1024 のモデルは
   学習中にこの状態を一度も見ていません（学習は最長 443）。**これが原因かは測っていません。**
   400–599 帯（大半は全層が全体を見る）でも下がっているので、それだけでは説明できません。
4. Phase 3（v0.1 の重みを推論時だけ 1024 で読む、配線確認のみ）は M2 0.849 → 0.653 と大きく
   変わりました。上書きが評価経路に届いていることの確認で、性能比較ではありません。

## 5. 判断していただきたいこと（候補）

1. **窓 128 を維持し、「窓が 2 つの弱点の原因」という仮説をこの測定で閉じる。**
   1 シードですが、差（M3 −0.0986、M2 −0.0972）は v0.1 の 3 シード幅（0.0454 / 0.0283）の
   2.2 倍 / 3.4 倍で、向きも逆です。私はこれを推します。
2. seed 1 / 2 を 1024 で追加して 3 対 3 で確かめる（seed 0 は起動からレポートまで 12 分 03 秒）。事前登録の規則では
   FAIL 後の追加学習はしない決まりなので、行う場合はご判断で。
3. 長文での急な低下（§4-3）を追うなら、「学習系列が 513 以下、評価系列が 513 超」の不一致を
   切り分ける別実験（長文を学習に入れる等）になります。データを変える実験なので別の事前登録が必要です。
4. `docs/benchmarks.md` §6 の「`local_attention: 128` はもっともらしい機構」という記述に、
   今回の対照実験（窓を広げても低下は消えなかった）を追記するかどうか。本書では触っていません。
