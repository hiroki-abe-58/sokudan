# v0.3 の候補: 包括的な選択肢（「その他」）が正解の例を学習に加える（事前登録、未実行）

2026-09-28 night_23 に記入しました。**判定規則だけを先に決めます。実行はしていません。** データの作成と学習の前に、この文書の規則は変えません。変える場合は、日付と理由を追記します。手順は `docs/research_protocol.md` に従います。

## 0. 動機（測った数字）

- `bench_ja` の部署ルーティングで、「その他」が正解の 38 件のうち、その他が選ばれたのは 11 件（recall 0.289）でした。`bench_en` は 17/48（0.354）です（`docs/benchmarks.md` §11）。
- `docs/probe_catch_all.md`（著者 1 人の 90 件）: 該当なしの state で「その他」が選ばれた率は、ランダムな順序で 0.295、その他を最後に固定すると 0.155 でした（10 項目 + その他）。
- 一方で、P(その他) で「正解がその他か」を分ける AUROC は 0.91〜0.94 でした。順位はあっても、argmax に届きません。
- 仮説: 学習データの choice に、「正解の選択肢がリストになく、包括的な選択肢が正解」の行がない（または少ない）ため、包括的な選択肢の確率が低く出ます。

## 1. 条件（データの作成は、学習の前に別途 commit する）

- **条件 ca8**: v0.1 の学習データの choice 行を元にします。
  - **(i)** 正解の選択肢を除き、包括的な選択肢を 1 つ足して、それを正解にした行。
  - **(ii)** 正解の選択肢を残したまま、包括的な選択肢を足した行（正解は元のまま）。
  - (i) と (ii) を、元の choice 行と同数ずつ加えます。
  - 包括的な選択肢の文言は複数用意します（例: 「その他: 上記以外」「該当なし」「上のどれにも当たらない」）。文言の一覧は、データの commit で固定します。
  - 選択肢の順序は、既存の学習と同じくランダムにします。包括的な選択肢も並べ替えの対象です。
- **設定**: そのほかは v0.1 と同じです（question_first、batch 24、累積 1、2 エポック、lr 2e-5、head lr 2e-4）。seed 0〜7 の 8 本です。
- **比較相手**: old16（v0.1 の設定の 16 本）です。

## 2. 評価セット（学習の前に作って固定する）

- **主評価セット**: `val_v2` の choice 1,976 行から、学習と同じ変換で作ります。
  - held-out（未知スキーマ）は bool の行だけなので、使えません。
  - `val_v2` は既存の choice acc を測ってきたセットです（`docs/multidomain.md`）。
  - **(i')**: 正解を除き、「その他: 上記以外」を**最後に固定**して足したもの。正解はその他です。
  - **(ii')**: 正解を残し、「その他: 上記以外」を最後に固定して足したもの。正解は元のままです。
  - 学習の包括的な選択肢の文言と、評価の文言（「その他: 上記以外」）が一致するかどうかも、データの commit で記録します。
- **副評価**（記述だけ。判定には使わない）:
  - `docs/probe_catch_all.md` のセット（B、C、D、ランダムな順序と最後に固定）。未知のスキーマでの包括的な選択肢は、これで見ます。
  - `bench_ja` の「その他」の recall。bench を使ってよいとチャット側が許可した場合だけ測ります。

## 3. 判定（機械的に適用）

**主指標（改善、片側）**:
- (i') で「その他」を選んだ率（argmax、その他は最後に固定）。
- ca8 > old16 を、8 対 16 の片側の正確置換、α = 0.05 で見ます。

**過剰選択の歯止め（非劣化）**:
- (ii') で「その他」を選んだ率（正解 ≠ その他）について、ca8 − old16 ≤ +0.02 を見ます。
- 片側の正確置換で、マージンは +0.02 です。

**非劣化**（`docs/multidomain.md` と同じマージン、8 対 16 の片側の正確置換、Holm で補正。M1m、M2、M5 は held-out、ほかは `val_v2`）:

| 指標 | マージン |
|---|---|
| M1m | −0.005 |
| M2 | −0.01 |
| M5 | −0.01 |
| choice acc（`val_v2`、変換前） | −0.005 |
| score acc（`val_v2`） | −0.01 |
| bool acc（`val_v2`） | −0.005 |
| score RPS（`val_v2`） | +0.005 |

- Holm の対象は、非劣化の 7 本と、過剰選択の歯止めの 1 本の、計 8 本です。
- **採用**: 主指標が改善し、かつ 8 本すべてで非劣化が示されたとき。
- **不採用**: それ以外。8 本そろわないときは「判定不能」です。
