# 遮蔽分析: 判断を決めている文は state のどこにあるか（規則は分析前に記録）

**探索的な分析で、判定はしません。** §1 は実行前に書いて commit しています。結果は §2 以降に追記します。

目的: 非明示の断り（`implies_declining`）と長文の意図について、判断を決めている文が state のどこにあるかを確かめます。
対象は、入力順のトレードオフ（`docs/noise_floor.md` §8: sf は M2 +0.045、M5 −0.044）です。

## 1. 規則（`scripts/occlusion.py`）

- **文の分割**（`split_sentences`）:
  - 「。」「！」「？」または改行の直後で文を区切ります。区切り文字は、それが終える文に含めます。
  - 最後の区切りより後ろの文字列も 1 文として扱います。
  - 空白だけの断片は候補にしません。ただし、ほかの文を取り除くときも本文には残します。
- **対象**:
  - **M5 側**: frozen held-out の `implies_declining` の行のうち、否定形でない設問で、ラベルが true のもの（**272 件**）。
  - **M2 側**: M2 の 210 行（state 400–799 トークン、frozen + `docs_long_val` の held-out）のうち、同じ条件のもの（**100 件**）。
  - 各事例の文数の平均: M5 6.7、M2 19.5。推論する行は全部で 4,154 行です。
- **Δ**: 各事例の各文 i について、文 i を取り除いた state で P(true) を計算します。
  Δ_i = P(true | 全文) − P(true | 文 i を除く)。
  - 条件ごとにシード平均します。v0.1 は `runs/v01_seed0〜7`（question_first）、sf は `runs/io_sf_seed0〜7`（state_first）。
  - 採点は `scripts/eval_local_attention.p_true` と同じです。
- **決定文**: v0.1 のシード平均 Δ が最大の文（Q3 では条件ごとに決めます）。
- **相対位置**: 決定文に重なるトークンの最初と最後の中点 / state のトークン長（特殊トークンなし、0〜1）。
  - 前 1/3（< 1/3）、中 1/3（< 2/3）、後 1/3 に分けます。
- **集計**:
  - **Q1**: `implies_declining` の正例で、決定文の相対位置の分布。
  - **Q2**: そのうち「v0.1 のシード平均 P ≥ 0.5 かつ sf のシード平均 P < 0.5」の事例（sf が取りこぼした断り）の、決定文の位置の分布。Q1 と並べます。
  - **Q3**: 長文 val の正例について、v0.1 と sf それぞれで決めた決定文の位置の分布。
- **予測**（実行前に記録）:
  - Q1 は前側に偏る。
  - Q2 は Q1 よりさらに前側に偏る。
  - Q3 は後側に偏る。
- **打ち切り**: 60 分を超えたら打ち切り、そこまでの結果だけを書きます（v0.1 と sf を交互に読み込むので、途中でも両条件のシード数がそろいます）。

## 3. 予測との一致

**読み取れること**（探索的。判定ではない）:

- 非明示の断りの「決め手の文」も、長文の意図と同じく state の後ろ側にありました。
  「断りの手がかりは冒頭に来やすい」という作業仮説は、この分析では支持されません。
- sf が取りこぼした断り（Q2）も、決定文はほとんど前 1/3 にありません。
  sf で M5 が下がる理由を「手がかりが mask から遠い前側にある」ことで説明するのは難しい、という結果です。
- 限界:
  - 決定文は「取り除くと P が最も下がる文」で、手がかりが複数の文に分かれている事例では 1 文に代表させています。
  - Q2 は n = 46 と小さい数です。
