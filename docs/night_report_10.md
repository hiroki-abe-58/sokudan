## 6. 予想と違ったこと

1. **断りの決定文は冒頭ではなく末尾寄りでした**（Q1 の後 1/3 は 0.548）。sf が取りこぼした断りも、前 1/3 にあるものはほとんどありません（Q2 は 3 / 46）。
   「sf は mask から遠い冒頭の手がかりを失う」という説明は、この分析では支持されません。sf で M5 が下がる理由は、まだ分かっていません。
2. **サンドイッチは両取りにならず、どちらの長所も取れませんでした。** 長文の効果（M2）は sf から v0.1 の水準に戻り、M5 も sf を有意に上回りませんでした。
3. **`ends_with_question` が大きく下がりました**（v0.1 と sf の 0.713 に対して 0.634）。同時に M1m が下がり、8 本中 2 本は M1m が破損の閾値（0.7912）を下回りました。
   ただし、破損停止の規則は seed 0 だけに適用されます。前後 2 つの mask の平均が、末尾の文で決まる属性を弱めている可能性があります（検定していない観察）。
4. 系列が質問ブロック 1 つ分長くなったことによる増加は、1 本あたり学習時間が約 +20%（v0.1 の 659 秒に対して 782〜809 秒）、peak allocated が約 +2 GiB でした。
