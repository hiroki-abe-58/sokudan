  - seed 0〜7 は、スコアラの初期値が制御されていなかったコードで学習したものです。再学習はせず、有効な標本として残します。

## 2. soup の作り方（部分集合は固定）

  - 浮動小数のテンソルを平均し、整数のテンソルは部分集合の最初のシードのものを使います。
  - config は最初のシードのものです（`scripts/ens_collect.make_soup` と同じ規則）。

## 3. 指標

- 指標は M1m、M2、M5、M1、ガードレール（choice acc、score RPS、score acc、bool acc）です。定義はこれまでと同じです。
  - 評価は事例ごとの予測から計算します（`scripts/ens_collect.py` と同じ採点）。
  - 単体の値は、保存済みの評価出力と一致することを確かめてから使います。
- **較正**:
  - bool の ECE: 10 分割、top-label（`sokudan.calibration.metrics.ece(probs, labels, n_bins=10)` を 2 列の確率に当てる）。
  - 「平均 P(true) − 正例率」。
  - どちらも単体 16 本とすべての soup で出します。
  - 集合は `val_v2` の bool 行（n = 7,862、温度をフィットする集合）と、frozen held-out の bool 行（n = 9,850）です。
  - **§5 の較正の規則には `val_v2` の値を使います。** held-out の値は記述です。

## 4. 検定と記述

- **主検定**: k = 4 の soup 4 個（n = 4）と単体 16 本（n = 16）を比べます。
  - M1m、M2、M5 のそれぞれで「soup > 単体」の片側の正確置換検定を行います（C(20, 4) = 4,845 通り、統計量は平均の差）。
  - **3 本に Holm 補正**をかけ、α = 0.05 で判定します。
  - **注記**: k = 4 の soup と単体は同じシードを共有していて、独立ではありません。これは近似の検定です（確認は bench で行う）。
- **独立な記述比較**（判定には使わない）: seed 8〜15 の soup（k = 8）を、単体 seed 0〜7 の分布と比べます。
  共有するシードがないので、完全に独立な比較です。z と、何本より上かを出します。
- **本数曲線**: M1m、M2、M5、score RPS について、k ごとの soup の平均値を表にします（k = 1 は単体 16 本の平均）。

## 5. 最終候補の条件と予測

- **最終候補の条件**: 次の 2 つを満たせば「**k = 16 の soup を bench 候補とする**」と記録します。**bench は実行しません**（実行するかはユーザーが別途確認する）。

  2. k = 16 の soup が M2、M5、ガードレールのすべてで、単体 16 本の平均以上である（RPS は平均以下）。
- **較正**: k = 16 の ECE（`val_v2` の bool）が単体 16 本の平均より 0.02 以上悪ければ、「温度の再フィットが必要」と記録します（今回はフィットしません）。
- **予測**（事前に記録）:
  - 本数曲線は k = 8 付近で頭打ちになる。
  - M1m と M5 は k とともに上がる。
